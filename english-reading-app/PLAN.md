# 영어 읽기 앱 — 구현 계획

## 목표
관심 주제(투자, 자기계발, 인간관계)의 짧은 영어 글을 B2 근처 난이도로 매일 재미있게 읽게 한다. 막히면 단어 뜻·문장 해석을 바로 보고, 원하면 한 줄 요약을 써서 피드백 받는다.

## 확정된 결정
| 항목 | 결정 |
|---|---|
| 형태 | claude.ai 비공개 Artifact, HTML 파일 1개. 폰 우선, PC 지원 |
| UI 언어 | 한국어 (본문만 영어) |
| AI | Artifact `sample` 기능 (API 키·서버 없음) |
| 글 고르기 | 제목 3개(정보성 기사 + 커뮤니티 썰 섞음) 중 선택 + 주제 직접 입력. 다시 받기 가능, 하루 제한 없음 |
| 길이 | 300~600단어 |
| 단어 도움 | 탭 → 문맥 뜻(한글). 어려운 단어는 글 생성 때 미리 받아 즉시 표시, 나머지는 탭할 때 AI 호출 |
| 문장 도움 | 길게 누르기 → 한글 해석 + 구조 설명 (AI 호출) |
| 전체 번역 / 단어장 | 없음 |
| 다 읽은 뒤 | 쉬웠음 / 적당 / 어려웠음 버튼 → 난이도 조절 |
| 요약 피드백 | 선택. 문법 교정 + 더 자연스러운 표현, 한글로. 점수·이해도 판정 없음 |
| 저장 | 클라우드(`db`)에 **난이도 숫자 하나만**. 글·기록·streak 저장 안 함 |
| 난이도 수동 변경 | 홈 화면 난이도 칩을 탭해서 직접 변경 |

## 화면 (목업 기준 4개)
1. **홈**: 난이도 칩(B2), 제목 카드 3개(유형 태그), 주제 직접 입력, "다른 제목 3개" 버튼
2. **읽기**: 제목, 난이도·예상 시간, 본문(serif). 단어 탭 → 하단 뜻 카드
3. **문장 해석**: 문장 길게 누름 → 하이라이트 + 해석/구조 카드
4. **다 읽은 뒤**: 난이도 버튼 3개, 한 줄 요약 입력(선택), 피드백 카드, "다음 글 고르기"

화면 전환은 JS로 섹션 하나만 보이게 하는 단순 상태(`home | reading | done`). 라우터 없음.

## 난이도 모델
- 단계: `B1, B1+, B2, B2+, C1` (인덱스 0~4), 기본값 `B2`(2)
- 쉬웠음 +1, 적당 0, 어려웠음 −1, 범위 0~4로 고정
- 이번 글에서 단어를 탭한 횟수는 다음 글 생성 프롬프트에 함께 넘겨서, 같은 단계 안에서 어휘 밀도를 미세 조정하게 함 (별도 저장 안 함, 앱 열려 있는 동안만)

## 데이터 (`db`)
- 문서 경로: `data/users/<userId>/settings` → `{ level: 2 }`
- `data/users/<id>/`는 본인만 접근 가능 → 별도 rules 불필요
- 읽기: 앱 시작 시 1회. 쓰기: 난이도 버튼/칩 변경 시에만
- `db`가 `null`(로그아웃 등)이면 B2로 시작하고 저장 없이 동작

## AI 호출 (`sample`)
모두 `sample.json`으로 JSON 응답. 매 호출에 필요한 지시·데이터 전부 포함(메모리 없음).

| 호출 | 입력 | 출력 | 티어 |
|---|---|---|---|
| 제목 3개 | 관심사, 난이도, (직접 입력 주제) | `[{type: "article"\|"community", title}]` ×3 | quick |
| 본문 | 제목, 유형, 난이도, 지난 글 탭 횟수 | `{paragraphs: [[sentence, ...], ...], glossary: [{phrase, ko, note}]}` | default |
| 단어 뜻 (미리 없는 단어) | 단어, 해당 문장 | `{ko, note}` | quick |
| 문장 해석 | 문장 | `{translation, structure}` | quick |
| 요약 피드백 | 본문 요약용 제목, 사용자 요약 | `{grammar: [..], natural: [..]}` | quick |

- 본문을 문장 배열로 받아서 문장 경계 파싱을 직접 안 함
- `glossary` phrase는 본문에서 대소문자 무시로 찾아 span으로 감쌈 (숙어 우선, 긴 것부터 매칭)
- 그 외 단어도 전부 탭 가능한 span. 같은 단어 재탭은 메모리 캐시로 재호출 안 함
- 에러: `not_granted` → AI 기능 안내 문구, `rate_limited` → "잠시 후 다시" 표시, 자동 재시도 없음

## 입력 처리
- 탭: `click` → 단어 뜻
- 길게 누르기: `pointerdown` 후 500ms 타이머 → 문장 해석, 그 후 click 무시. `contextmenu` 기본 동작 막기
- 요약 제출 시 빈 입력이면 인라인 에러, 호출 안 함

## 구현 순서
1. HTML 뼈대 + 토큰(라이트/다크) + 3개 상태 전환
2. `db`/`user` 연결, 난이도 읽기·쓰기, 난이도 칩
3. 제목 3개 생성 + 직접 입력
4. 본문 생성 + 단어 span 렌더링 + glossary 즉시 뜻
5. 단어 fallback 호출, 문장 길게 누르기 해석
6. 다 읽은 뒤: 난이도 버튼, 요약 피드백
7. 로딩·에러 상태, 폰 폭(375px) 레이아웃 점검

## 검증
- 순수 함수 2개(난이도 조정, glossary 매칭)에 페이지 로드 시 `console.assert` 자체 점검
- 게시 후 `ArtifactData list`로 `data/users/...` 문서에 level이 써지는지 1회 확인
- 폰 폭에서 탭/길게 누르기 동작 확인

## 하지 않는 것
streak, 읽은 글 기록, 단어장·복습, 전체 번역, 이해도 판정, 점수, 실제 기사 크롤링, 로그인 화면
