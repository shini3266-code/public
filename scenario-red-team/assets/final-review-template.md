# 최종 심사 결과 템플릿

종료 조건을 충족하면 아래 8개 항목을 이 순서대로 정리한다. 사용자가 원하면 `{대상}_scenario_review_{YYYYMMDD}.md` 파일로 저장한다 (파일 첫머리에 제목, 작성일, 검토 대상 시나리오 요약을 붙인다).

1. **종합 판정**: 견고함 / 보강 필요 / 취약 / 재작성 필요 — 이유 2~3줄
2. **5개 축 평가표**

| 축 | 점수(1~5) | 핵심 근거 |
|---|---|---|
| 수치 적절성 | | |
| 논리 일관성 | | |
| 현실성(확률) | | |
| 타당성 | | |
| 편향 균형 | | 낙관/비관 중 어느 쪽으로, 얼마나 |

3. **가정별 판정표**: 가정, 영향도, 판정(타당/의문/취약/모순), 근거
4. **확률 재추정**: 사용자 원래 확률 vs 검토 후 추정 확률, 조건 연쇄 계산식 포함
5. **수정 제안 시나리오**: 비현실적인 가정을 현실적인 범위로 바꿨을 때의 결론(목표가·수익률 범위) — 원본과 나란히 비교
6. **열린 리스크**: 끝내 해소되지 않은 질문 목록
7. **가설 무효화 신호**: 앞으로 무엇이 관측되면 이 시나리오를 버려야 하는가 2~3개, 확인 시기 포함
8. **출처 목록**: 검토 중 대조한 자료 (제목, 발행처, 날짜, URL)

> 면책: 본 심사는 시나리오의 견고성을 평가한 것이며 투자 권유가 아닙니다. 투자 판단과 책임은 투자자 본인에게 있습니다.
